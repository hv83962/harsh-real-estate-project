# Harsh Real Estate - Web Platform

A full-stack property listing and valuation portal built with PHP, MySQL, Bootstrap 5, and React 18.

## 🌟 Key Features
- **Property Discovery & Search:** Dynamic AJAX-based filters by location, type (Apartment, House, Flat, Commercial, Plot), BHK, and budget.
- **Dual Purpose Listings:** Explicit categorization for **FOR SALE** and **FOR RENT** properties with custom badges and rental pricing.
- **Interactive React 18 Estimator:** Client-side instant property valuation and home loan monthly EMI calculation.
- **Interactive Maps & Details:** OpenStreetMap (Leaflet) integration rendering localized property coordinates and specs.
- **Role-Based Portals:** User/Seller Dashboard for property CRUD actions, favorites bookmarking, and an Admin Panel for lead management.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5, Vanilla JavaScript, React 18 (Babel-standalone)
- **Backend:** PHP 8.x (RESTful JSON Endpoints)
- **Database:** MySQL / MariaDB (PDO with Prepared Statements)
- **Maps:** Leaflet.js / OpenStreetMap
